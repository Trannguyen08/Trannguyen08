## 🔄 Quy trình CI/CD
 
<div align="center">
  <img src="./assets/pipeline.svg" alt="CI/CD pipeline" width="100%" />
</div>
<details>
<summary><b>📄 Xem workflow GitHub Actions mẫu</b></summary>
```yaml
name: CI/CD
 
on:
  push:
    branches: [main]
  pull_request:
 
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -r requirements.txt
      - run: ruff check .
      - run: pytest
 
  build:
    needs: test
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: docker build -t app:${{ github.sha }} .

 
</details>
